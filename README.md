# Cody AI Agent

**Автономный AI-агент-программист для терминала.**  
Работает через **Timeweb Cloud** — без VPN, без зарубежных карт, без блокировок.

![Cody AI](datas/logo.ico)

---

## О проекте

Cody — это терминальный AI-агент, вдохновлённый Cline, Codex и Cursor Agent. Он понимает задачу на естественном языке, разбивает её на шаги, создаёт и редактирует файлы, запускает код и работает с документами. Управление — прямо в командной строке.

Проект создан специально для **пользователей из России**, у которых возникают сложности с прямым доступом к зарубежным AI-провайдерам (OpenAI, Anthropic, Google AI). Cody использует **API Timeweb Cloud** — российского облачного провайдера с поддержкой современных нейросетей:

- GPT-5.5, GPT 5.4, GPT-6 Astra
- Claude 4.5 / 4.6 / 5
- Gemini 3.1 / 3.5 / 3.6
- DeepSeek V4, Grok 4.5, Qwen 3.x
- YandexGPT 5.1, GigaChat, GLM 5.x, Kimi K2.x

Все модели доступны через единый API без зарубежных платёжных систем.

## Возможности

### Работа с кодом
- Создание файлов и проектов одним промтом
- Редактирование конкретных строк кода
- Замена содержимого файла целиком
- Удаление файлов и папок
- Создание структуры проекта с вложенными директориями

### Контекст проекта
- Автоматический сбор всех текстовых файлов проекта
- Построение дерева директорий
- Учёт содержимого файлов при генерации кода
- Поддержка 50+ языков программирования и разметки

### Работа с документами
- Извлечение текста из `.docx`
- Извлечение текста из `.pdf`
- Чтение `.txt`, `.md`, `.csv`, `.log`
- Прикрепление документов к запросу через команду `/attach`

### Интерфейс терминала
- Плавная анимация размышления агента
- История диалогов в локальной базе SQLite

### Работа из любой папки
- Добавление в системный PATH
- Запуск одной командой `cody` из любого каталога
- Агент редактирует файлы в текущей директории

## Быстрый старт

### Требования
- Windows 7 /8 / 8.1 / 10 / 11
- Аккаунт Timeweb Cloud с активным агентом

### Установка

**Вариант 1. Готовый `.exe`**

1. Скачайте `cody.exe` из раздела Releases.
2. Поместите рядом папку `datas` с файлами `config.json` и `logo.ico`.
3. Запустите `cody.exe`.

**Вариант 2. Установщик**

Скачайте `Cody_AI_Setup_v1.0.0.exe` из Releases. Установщик сам создаст ярлыки, добавит программу в PATH и настроит рабочую среду.

### Настройка API

Откройте файл `datas/config.json` и укажите:

```json
{
    "access_id": "ваш_access_id",
    "api_token": "ваш_api_token",
    "openai_url": "https://agent.timeweb.cloud/api/v1/cloud-ai/agents/<ID>/v1",
    "model": "GPT OSS 120B",
    "temperature": 0.2
}
```

Все данные выдаются в панели Timeweb Cloud после создания агента.

### Первый запуск

```bash
cody
```

Вы увидите приглашение:

```
Cody AI > готов
Вы > _
```

Введите промт и нажмите Enter.

## Примеры использования

### Создание файла

```
Вы > напиши python скрипт который выводит привет мир
```

Агент создаст `hello.py` в текущей папке.

### Создание проекта

```
Вы > создай лендинг страницу с тремя секциями и формой обратной связи
```

Агент создаст `index.html`, `style.css`, `script.js` в текущей директории.

### Редактирование кода

```
Вы > в файле main.py в строке 12 ошибка IndexError, исправь
```

Агент прочитает файл, найдёт строку и заменит её.

### Работа с документом

```
Вы > /attach requirements.docx
Вы > создай проект по требованиям из документа
```

Агент извлечёт текст из документа и создаст структуру проекта.

### Запуск кода

```
Вы > запусти hello.py
```

Скрипт запустится, вывод появится в терминале.

## Команды агента

| Команда | Описание |
|---|---|
| `/exit`, `/quit` | Выход из программы |
| `/cd <путь>` | Сменить рабочую директорию |
| `/pwd` | Показать текущую директорию |
| `/ls` | Список файлов в текущей папке |
| `/tree` | Дерево проекта |
| `/attach <файл>` | Прикрепить файл к следующему запросу |
| `/attached` | Показать прикреплённые файлы |
| `/clear` | Очистить экран |
| `/help` | Справка по командам |

## Как это работает

1. Пользователь вводит задачу на естественном языке.
2. Агент собирает контекст: все текстовые файлы проекта, дерево директорий, прикреплённые документы.
3. Запрос отправляется в API Timeweb Cloud с системным промтом, описывающим формат ответа.
4. Модель возвращает JSON с планом и списком действий.
5. Агент выполняет действия: создаёт, редактирует, удаляет файлы или запускает код.
6. Контекст обновляется, цикл повторяется до завершения задачи.

Агент поддерживает многошаговые задачи: если модель возвращает `done: false`, цикл продолжается. Это позволяет выполнять сложные задачи, требующие нескольких итераций.

## Совместимость моделей

Cody работает с любой моделью, доступной через OpenAI-совместимый API Timeweb Cloud. Актуальный список моделей публикуется в панели провайдера.

- **Anthropic** — Claude 4.5 Haiku, Claude 4.6 Sonnet, Claude 4.7 Opus, Claude 5
- **Google** — Gemini 3.1 Flash, Gemini 3.5, Gemini 3.6, Gemini 3.7, Gemini 3.8
- **DeepSeek** — V4 Flash, V4 Pro, V4.1 Flash
- **xAI** — Grok 4.3, Grok 4.5, Grok 4.6, Grok Code Fast
- **Alibaba** — Qwen 3.5, Qwen 3.6, Qwen 3.7, Qwen 3.8
- **Яндекс** — YandexGPT 5.1 Pro, YandexGPT 5.1 Lite, Alice AI LLM
- **Прочие** — GLM 5.x, Kimi K2.x, Kimi K3, Moonshot

Модель выбирается в `config.json` в поле `model`.
